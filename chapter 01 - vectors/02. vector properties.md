# Свойства векторов

*Свойства векторов описывают геометрические и алгебраические характеристики, которые определяют поведение векторов. В этом файле: длина, направление, единичные векторы, равенство, параллельность, ортогональность и линейная независимость — кирпичики, из которых сложено любое пространство признаков в ML.*

- **Длина** (или модуль, magnitude) вектора говорит, *как далеко* он дотягивается. Считайте, что это длина стрелки. Для вектора $\mathbf{a} = (a_1, a_2, a_3)$ его длина равна:

$$\|\mathbf{a}\| = \sqrt{a_1^2 + a_2^2 + a_3^2}$$

- Это просто теорема Пифагора, распространённая на большее число измерений: мы меряем расстояние по прямой от начала координат до точки.

- **Направление** вектора говорит, *куда* он указывает; достаточно мысленно провести прямую из начала координат в точку с этими координатами.

- Когда начало координат явно не задано, мы обычно подразумеваем точку (0,0,...0) — центр, по крайней мере для наглядности.

- Положение не имеет значения, речь всегда о смещении: вектор $(3, 2)$, отложенный от начала координат, и такой же $(3, 2)$, отложенный от другой точки, — это по-прежнему один и тот же вектор.

![Равенство векторов: один и тот же вектор (3,2), отложенный от двух разных начальных точек](../images/vector_equality.svg)

- Два вектора могут иметь одинаковую длину, но указывать в совершенно разные стороны — или указывать в одну сторону, но различаться длиной.

![Одинаковое направление при разной длине (v и 2v) против одинаковой длины при разных направлениях](../images/magnitude_direction.svg)

- Два вектора **равны** тогда и только тогда, когда совпадают все их соответствующие компоненты: та же длина, то же направление, ровно та же стрелка.

$$\mathbf{a} = \mathbf{b} \iff a_i = b_i \text{ для всех } i$$

- Два вектора **параллельны**, если один получается из другого умножением на скаляр. Они лежат вдоль одной прямой — либо сонаправленно, либо строго противоположно.

$$\mathbf{a} \parallel \mathbf{b} \iff \mathbf{a} = k\mathbf{b} \text{ для некоторого скаляра } k \neq 0$$

![Параллельные векторы: a и b смотрят в одну сторону, a и -b — в противоположные](../images/parallel_vectors.svg)

- Если $k > 0$, они смотрят в одну сторону. Если $k < 0$ — в противоположные. В любом случае они лежат на одной прямой, проходящей через начало координат.

- Интуитивно параллельные векторы не несут «новой» информации о направлении. Один — просто растянутая или развёрнутая версия другого.

- Два вектора **ортогональны** (перпендикулярны), если они указывают в совершенно независимых направлениях. Движение вдоль одного не даёт никакого продвижения вдоль другого.

![Ортогональные векторы: u и v сходятся под прямым углом](../images/orthogonal_vectors.svg)

- Представьте, что вы идёте на север, а потом на восток: это ортогональные направления — сколько ни иди на север, восточнее вы не окажетесь. С ортогональностью мы будем встречаться очень часто.

- Ортогональность занимает в ML центральное место: ортогональные признаки несут полностью независимую информацию, а это идеальный случай для представления данных.

- В общем случае между любыми двумя векторами есть **угол** $\theta$ в диапазоне от $0°$ до $180°$.

- Этот угол исчерпывающе описывает отношение между двумя направлениями: $0°$ означает параллельность (одна сторона), $180°$ — тоже параллельность (противоположные стороны), а $90°$ — ортогональность. Всё, что между, — это смесь.

- Большинство отношений между векторами в ML находится где-то на этой шкале. Позже мы разберём точные инструменты для вычисления такого угла — скалярное произведение и косинусную близость (cosine similarity).

- Набор векторов **линейно зависим**, если хотя бы один из них можно собрать из остальных с помощью масштабирования и сложения. Такой вектор не добавляет набору никакой новой информации.

- Например, если $\mathbf{c} = 2\mathbf{a} + 3\mathbf{b}$, то $\mathbf{c}$ избыточен: всё, что даёт $\mathbf{c}$, у вас уже есть через $\mathbf{a}$ и $\mathbf{b}$.

- Параллельные векторы всегда линейно зависимы, ведь один — просто отмасштабированная копия другого. Любой набор, содержащий нулевой вектор, тоже линейно зависим.

- Векторы **линейно независимы**, если ни один из них нельзя собрать из остальных. Каждый добавляет по-настоящему новое направление. Ортогональные векторы всегда линейно независимы.

- Немного интуиции: если вы хотите изучать разных людей и представлять их векторами, то линейно зависимые векторы (люди) перекосят наблюдение в пользу переизбыточно представленной точки данных — важный фактор при подготовке набора данных для обучения ИИ.

- На плоскости двух линейно независимых векторов достаточно, чтобы добраться до любой точки. В трёхмерном пространстве нужно три. Эта мысль — «сколько независимых векторов вам нужно» — напрямую связана с размерностью.

- Вектор называется **разреженным** (sparse), когда большинство его компонент равны нулю. Противоположный случай, когда большинство компонент ненулевые, называется **плотным** (dense).

$$\mathbf{s} = [0, 0, 3, 0, 0, 0, 1, 0, 0, 0]$$

- Разреженность важна, потому что влияет и на хранение, и на вычисления. Разреженные векторы можно хранить и обрабатывать гораздо эффективнее, отслеживая только ненулевые элементы.

- **Единичный вектор** — это вектор длины ровно 1. Он несёт в себе чистое направление, без всякой информации о длине. Любой вектор можно превратить в единичный, разделив его на собственную длину:

$$\hat{\mathbf{a}} = \frac{\mathbf{a}}{\|\mathbf{a}\|}$$

- Этот приём называется **нормализацией**. Он отбрасывает «как далеко» и оставляет только «в какую сторону» — в машинном обучении это важный инструмент.

- Стандартные единичные векторы направлены вдоль осей: $\hat{\mathbf{i}} = (1, 0, 0)$, $\hat{\mathbf{j}} = (0, 1, 0)$, $\hat{\mathbf{k}} = (0, 0, 1)$. Любой вектор можно записать как их комбинацию, например $(3, 2, 4) = 3\hat{\mathbf{i}} + 2\hat{\mathbf{j}} + 4\hat{\mathbf{k}}$.

## Задания на код (используйте CoLab или ноутбук)

1. Вычислите длину вектора и убедитесь, что она совпадает с результатом по теореме Пифагора, а затем измените код так, чтобы он считал единичный вектор.
```python
import jax.numpy as jnp

a = jnp.array([3.0, 4.0])

magnitude = jnp.sqrt(jnp.sum(a ** 2))
print(f"Magnitude of a: {magnitude}") 
```

2. Проверьте, параллельны ли два вектора, — то есть является ли один произведением другого на скаляр.
```python
import jax.numpy as jnp

a = jnp.array([2, 4, 6])
b = jnp.array([1, 2, 3])

ratios = a / b
print(f"Ratios: {ratios}")
print(f"Parallel: {jnp.allclose(ratios, ratios[0])}")
```
