# Глоссарий терминов

Единый словарь для всего перевода: один английский термин — один русский вариант во всех главах. Пополняется по мере перевода глав.

Условные обозначения в колонке «Примечание»:
— *англицизм* — оставляем как есть, русская калька режет слух практикам;
— *с оригиналом* — при первом упоминании в файле даём английский вариант в скобках.
